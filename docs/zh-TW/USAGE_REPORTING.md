# 首次啟用與匿名安裝統計

[English](../en-US/USAGE_REPORTING.md) · [简体中文](../zh-CN/USAGE_REPORTING.md) · [日本語](../ja-JP/USAGE_REPORTING.md) · [한국어](../ko-KR/USAGE_REPORTING.md) · [繁體中文](../zh-TW/USAGE_REPORTING.md)

Monitor Go 與 Monitor Console 是獨立倉庫、服務和資料庫，原始碼及資料目錄分開保存。安裝 Monitor Go 只需本公開倉庫，不依賴私有 Console 原始碼。首次安裝連線至設定的 Console 線上登記；後續本機登入、監控和告警獨立運作。

標準新安裝須先線上啟用，再建立首個本機管理員。頁面顯示確切目的地、統計用途、欄位及持續回報且沒有關閉開關的規則，要求明確確認告知版本 `2`。登記失敗不建立管理員，恢復後沿用隨機身分重試。產品使用者不需要 Console 帳號。

統計獨立安裝量、活躍安裝量及產品版本/系統分布：v2 登記為 `instanceId`、`credential`、`version`、`os`，回報為 `instanceId`、`version`、`os`、`activeDays`。隨機編號用於去重，獨立憑證只供認證，活躍標記依 UTC 日期彙總。版本和系統類型屬技術分布，不關聯產品使用者帳號；不傳送架構、部署方式、成員清單、主機名稱/IP、監控內容、檔案、密碼或監控/應用程式金鑰。匿名統計 User-Agent 固定，不附建置版本。

產品使用者帳號綁定、綁定碼、使用者清單及我的執行個體功能已退役。Console 僅保留後台管理員自身的認證資訊，以管理統計服務；這些管理員不代表產品使用人數。Monitor Go 的本機管理員、成員與權限功能仍獨立運作。

統計依隨機安裝身分去重，不代表實際使用人數。同一安裝多人使用仍只計一次；複製資料目錄可能合併統計，建立空目錄可能產生另一個安裝。遠端登記成功後若本機初始化失敗或取消，後台可能保留隨機登記，因此登記數也不等於完成安裝數。

獨立工作在啟用後回報，之後約每 6 小時加入隨機間隔；請求 5 秒逾時、禁止重新導向並採有限退避。最多保留 7 個待傳送 UTC 活躍日期；單純載入頁面和自動更新不計活躍。Console 每日記錄保留 90 天，365 天未回報的安裝會清理，後續可再次登記。

目的地不變時，升級保留隨機身分、憑證、啟用狀態、歷史確認及活躍日期。減少欄位不補造同意，告知版本仍為 `2`。舊版關閉的安裝須管理員確認目前目的地及規則，登記成功後才啟用；確認等待或 Console 不可用時，本機登入、監控及告警持續運作。變更接收方須先確認新目的地才能傳送。持續回報仍沒有關閉開關，關閉請求回傳 HTTP 403。

先升級 Monitor Console 至結構版本 `3`，再升級 Monitor Go 至結構版本 `12`。新版用戶端使用 `/api/v2/instances/register`、`/api/v2/instances/report`；Console 的 v1 登記/回報相容舊用戶端，保留版本與系統類型，收到架構和部署方式後丟棄，不保存或回傳。綁定介面已退役。Monitor Go v11 實體移除 `usage_settings.account_login` 舊快照；Console v3 移除架構、部署方式、帳號關聯及綁定碼，保留版本/系統分布及匿名計數。

升級前正常停止服務並分別完整備份兩套資料目錄；回復時還原各自舊映像/執行檔及整套升級前備份，不能共用資料庫。舊備份可能仍含已退役資料，應私密管理。目的地未變且已確認的安裝，不必清空 Monitor Go 資料重新啟用。

未設定 `MONITOR_CONSOLE_URL` 時使用內建預設 HTTPS 來源，實際位址以安裝或確認頁面為準；明確的環境值覆寫預設，`-console-url` 優先於環境變數。繼續使用原後台時，請在升級前明確設定其 HTTPS 來源。空值或只有空白的目的地無效。舊 `-require-activation=false` / `MONITOR_REQUIRE_ACTIVATION=false` 會被拒絕，`true` 保持相容；版本查詢與備份命令不依賴啟用設定。

僅支援 HTTPS；數字迴環 HTTP 只供隔離整合測試。不要將憑證、資料目錄或備份提交 Git，統計代理記錄不要保存完整來源 IP 或憑證。`MONITOR_DEPLOYMENT` / `-deployment` 仍標示本機執行方式，但不再傳送為匿名統計欄位。

```sh
./bin/monitor -data data -listen 127.0.0.1:5080
```
