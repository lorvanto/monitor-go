# 项目协作说明

本说明是根目录 [AGENTS.md](../../AGENTS.md) 的中文版本，适用于整个仓库；维护时同步更新中英文说明。下文中的文件路径和命令均以仓库根目录为基准。

## 项目边界

项目统一名称为 Monitor Go，仓库和 Go module 使用 `monitor-go`。界面、文档、协议标识、部署配置和示例保持一致，仅维护本项目资料。

这是独立的 Go 监控运维项目，使用内置 SQLite 文件数据库，支持单套安装内多人协作，不做多租户。当前已实现五类页面、Go + SQLite 后端、远程 Agent、SMTP / Webhook 通知、菜单与文件管理、图片样式、基础设置、操作审计、应用密钥、安装包与二维码条码，实际能力与边界见 README。继续实施以用户确认的任务为准。

先阅读 [中文文档索引](INDEX.md)。文档区分已确认要求、建议方案和未实现功能，不得把建议写成已经实现的事实。

## 开发约束

- 所有新代码、资源、文档和构建配置位于本仓库，不引用相邻项目作为运行依赖。
- 不复制外部数据库配置、密码、令牌、私钥、运行数据或 Git 历史。
- 用户未要求时，不删除其他项目、不迁移真实数据库、不创建远程仓库、不发布版本。
- 按业务模块组织代码，接口使用明确的类型，事务边界由业务操作决定。
- 存储只支持 SQLite，不引入 MySQL 存储适配、外部 Redis 或消息队列作为安装依赖。MySQL 与 Redis 检测属于业务探测能力。
- 菜单展示和服务端权限分开实现，新增写接口必须有对应的权限检查。
- 资源归本套安装共享，创建人字段用于审计，不能暗中当作数据隔离条件。
- 业务配置优先软删除；历史指标按明确的保留策略到期清理。
- 保留 Go、前端和数据库的锁定文件；选择依赖时记录版本与用途。
- 简体中文文档集中在 `docs/zh-CN/`，繁体中文文档位于 `docs/zh-TW/`；目录与文件名使用英文，新增文档同步更新索引。

## 验证要求

- Go 实现后运行格式检查和 `go test ./...`，并按变更范围执行构建、竞态检查或集成测试。
- 前端采用 React 19 + TypeScript + Vite，使用 Zustand 管理共享及页面状态，页面按需加载；新增组件使用 TSX，不引入另一套 UI 运行时。
- 前端实现后运行类型检查、React 交互测试和生产构建，修改关键交互时验证浏览器实际行为。
- 数据库变更必须在实际 SQLite 文件上验证迁移、约束、事务和核心业务集成测试，不能只用内存替身。
- API 变更要启动本项目服务做真实 HTTP 验证，记录实际端口，避免测试到旧服务。
- 容器变更运行 `docker compose config --quiet` 和 `node scripts/test-docker.mjs`，用临时数据卷验证目标平台、持久化与停机备份恢复，不把运行中实例的数据挂到测试容器。
- 文档或纯目录调整只做对应的文件、链接和仓库独立性验证。

## 国际化维护

- 共享文案放在 `locales/`，首批支持简体中文、英文、日文、韩文与繁体中文。新增可见文案同步五语目录，保留插值参数。 新浏览器默认英文，有有效保存选择时恢复，不自动跟随浏览器语言。
- 界面显示文字不能作为状态码、权限键、查询值或数据库枚举。用户名称、备注、文件与历史记录保留原文。
- 国际化变更运行 `npm --prefix web run check:i18n`、`npm --prefix web test`，并验证语言切换不清空编辑内容。
- 根 README 为英文入口；五语文档统一按 `docs/<locale>/` 组织，简体中文设计文档集中在 `docs/zh-CN/`。部署命令、支持范围和前提变化时同步当前五语指南。

## GitHub 文档与发布

- 项目自有代码与文档采用 Apache-2.0，保留 `LICENSE`、`NOTICE` 与第三方许可文本。新增依赖同步更新 `THIRD_PARTY_NOTICES.md`。
- 根目录社区文档使用英文；中文发布与贡献说明集中在 `docs/zh-CN/GITHUB.md`，相关五语入口同步维护。
- `CHANGELOG.md` 的 Unreleased 与应用版本不代表已经发布。不得编造标签、下载地址、CI 状态或平台验证结果。
- 文档改动运行 `npm --prefix web run check:docs`，其范围包含根目录、`docs/` 和 `.github/`。修改检查脚本时另运行 `npm --prefix web run test:docs`。
- 创建远程仓库、推送与发布在实际收到发布任务时执行；本地文档准备不等于已经执行发布。
