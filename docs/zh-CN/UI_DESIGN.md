# 界面与交互规划

> 文档类型：当前视觉规范与后续交互规划。当前使用方式以 [使用指南](README.md) 为准，公开发布流程见 [GitHub 发布指南](GITHUB.md)。

管理端重新设计页面和操作路径，以异常定位、资源管理和团队操作为核心。下文描述完整产品规划。首轮已在 `web/` 实现总览、主机详情、检测列表、告警处理、角色授权五类页面，并接入 Go + SQLite 真实数据。已增加初始化、登录与成员编辑表单，远程 Agent 和外部通知交互，以及菜单、文件、图片样式、审计、系统设置页面。后文其余页面仍为规划。运行方式见仓库 README。

## 导航结构

| 一级入口 | 页面 |
|---|---|
| 总览 | 异常概览、告警摘要、证书到期、最近任务、快速接入 |
| 主机 | 主机列表、主机详情、分组 |
| 检测 | 服务检测、SSL 检测、检测历史、分组 |
| 证书 | 证书列表、申请订单、ACME 账号 |
| 告警 | 事件、规则、通知渠道、维护窗口、通知记录 |
| Agent | 设备列表、安装凭据、安装引导 |
| 文件 | 文件浏览、图片样式、存储配置 |
| 应用 | 接入应用、API 凭据、安装包 |
| 系统 | 用户、角色、菜单、任务、审计、设置、关于 |

主机和检测页面直接展示所属分组、最近状态和可执行操作。每个模块复用同一套分组组件，避免为相同分组操作维护多套交互。

安装后生成默认导航。管理员可调整菜单名称、顺序、图标和可见性；内部页面通过页面注册表选择。界面不让用户填写源码路径或 API method。

## 视觉规范（已实现）

2026 年 10 月 14 日重新设计管理端界面，替换首版原型样式，覆盖全部 12 个页面与登录、初始化页。界面本身保持中性的石墨与纸白，颜色只表达状态和数据：红色只在出现故障时出现。令牌与组件样式集中在 `web/src/styles.css`，按 tokens → reset → base → components → shell → pages → utilities 分层。

| 项目 | 规则 |
|---|---|
| 状态 | 正常 ● 绿、需关注 ▲ 琥珀、异常 ■ 红、暂停 ‖ 灰、待定 ○ 灰、处理中 ◆ 墨色。状态始终同时显示形状和文字，不只靠颜色区分 |
| 信号条 | 检测历史从左到右由旧到新，异常越严重柱越高。用于总览看板、检测列表和检测详情，是界面唯一的标志性图形，品牌标志与网站图标沿用同一形状 |
| 字体 | 拉丁字母与数字使用 IBM Plex Sans 可变字重；主机地址、路径、哈希、版本号、应用标识等机器字符串使用 IBM Plex Mono；中文使用系统字体。字体随前端资源嵌入，不访问外网 |
| 数字 | 表格列与坐标刻度使用等宽数字；读数条和大号数值使用比例数字，单位缩小并降低对比 |
| 表面 | 页面底色上放置白色面板，以 1px 分隔线区分层次；只有弹窗、菜单和提示使用阴影。圆角按层级区分：标签 3px、控件 6px、面板 8px、弹窗 12px |
| 图表 | 单序列只用蓝色；网络入站 / 出站为蓝色与洋红，已用色觉安全校验脚本验证明暗两种模式。2px 折线、10% 面积、实线网格；时间轴固定为所选窗口，缺失区间留空；十字准线显示各序列数值，图表获得焦点后可用方向键逐点查看 |
| 主题 | 浅色与深色分别取值，并非简单反色。首次访问跟随系统设置，手动切换后记住选择 |
| 布局 | 左侧栏集成实例名称、页面搜索（⌘K / Ctrl K）、导航、连接状态、主题切换与账号菜单，桌面端不再设顶栏。960px 以下侧栏收起为抽屉并显示简易顶栏，检测列表改为堆叠卡片 |
| 页面结构 | 页头只放标题、一句事实说明和主要操作，不放标语或装饰横幅；筛选集中在内容上方的一行工具栏 |
| 详情与表单 | 新建与编辑使用居中弹窗；检测、安装包详情使用右侧抽屉，保留列表上下文。危险操作使用红色按钮并写明动作名称 |
| 无障碍 | 正文、次要文字与状态文字对比度达到 WCAG AA（4.5:1）；键盘焦点可见；弹窗管理焦点并支持 Esc 关闭；遵循“减少动态效果”系统设置 |

总览以一句状态标题开头（例如“3 项异常需要处理”），随后是在线主机、检测正常、24 小时可用率、未恢复告警四项读数，再往下是响应趋势与检测看板、需要关注的告警、主机资源和最近操作。可用率与平均响应按近 24 小时计算，响应曲线随所选时间范围按时间桶平均。

以下仍为规划：表格常规 / 紧凑两种密度切换、专业参数的可展开设置区、页面级任务进度提示。

## 首次使用

1. 本地命令生成一次性初始化凭据，用户访问安装页面。
2. 创建首个管理员，设置站点名称、访问地址和显示时区。
3. 进入引导，可选择安装 Agent、添加站点或配置通知。
4. 测试连接或首条检测后展示明确结果。
5. 跳过引导后仍可在总览重新打开。

初始化完成后关闭安装入口。数据库为空或迁移失败与普通登录错误分开提示。安装页不公开服务器环境变量、数据库密码或完整运行配置。

## 新建检测流程

先选择检测类型和执行位置，再填写目标。表单按类型展示必要字段：HTTP 状态与请求条件、TCP 端口、数据库连接、SSL 提醒阈值。

测试连接使用尚未保存的配置，执行权限与正式检测一致，返回可理解的成功或失败信息。测试成功不自动创建资源。保存后可以选择立即执行一次，并看到任务进度。

导入先解析并展示预览，包括可创建、重复、格式错误和缺少关联项的行。用户确认后创建任务，结果逐行可下载。导出默认不包含密码、API Key 或设备凭据。

## 告警处理流程

告警详情以时间线展示首次异常、达到阈值、通知结果、确认、静默和恢复。确认操作记录处理人，静默操作显示结束时间，维护窗口展示匹配范围。

界面区分“当前故障状态”和“通知状态”。通知失败时展示重试情况，不把告警显示为已经处理。恢复状态由检测判断，人工操作若要关闭事件必须有明确语义和审计。

## 证书申请流程

域名与算法 → 验证方式 → 验证操作 → 检查并签发 → 下载与部署说明。

DNS TXT 信息可复制，并解释需要放入哪个域名记录。HTTP 文件验证同时显示目标 URL 和文件内容；写入本机目录与部署到远程站点分开说明。

手动验证证书标注“需要人工完成验证”。可自动续期的证书显示最近执行结果和下次计划。证书已经签发、文件已经下载、线上服务已经使用新证书是不同状态。

## 多人编辑与权限反馈

保存时发生版本冲突，弹窗说明由其他成员修改，并保留当前输入。提供重新加载和对比选项，不能直接覆盖。

无权限的菜单隐藏；页面内不可执行操作可隐藏或显示禁用原因，以一致规则处理。用户直接访问无权限 URL 时显示 403 页面。角色更改后刷新当前权限状态，后台接口同时独立校验。

批量操作先显示选中数量和影响范围，结果逐项呈现。删除分组有资源时引导先转移；停用 Agent 提示将影响的主机和检测目标。

## 通用状态与可访问性

每类页面都定义加载、空数据、错误、权限不足、部分成功、数据过期和连接中断状态。空页面给出下一步操作；请求失败保留筛选条件和未提交输入。

表单支持键盘操作、明确标签和逐字段错误，弹窗管理焦点并可按 Escape 关闭适合关闭的操作。图表有文本摘要，颜色不作为唯一信息来源。

桌面端优先完整管理，移动端支持总览、告警处理和资源状态查看；复杂权限树和批量导入允许采用专门的窄屏布局。核心用户流程在常见桌面与手机宽度分别验收。

## 更新与国际化

首版界面使用中文，文案集中管理并预留英文语言包位置。时间和数字按显示设置格式化，后端存储保持统一单位。

实时状态先使用受控轮询，页面不可见时降频或暂停。异步任务可采用 SSE 推送进度；断线后通过任务接口恢复状态。列表筛选、分页、排序和时间范围同步到 URL，便于团队分享相同视图。
