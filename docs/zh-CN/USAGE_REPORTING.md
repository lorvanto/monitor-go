# 首次激活与匿名安装统计

[English](../en-US/USAGE_REPORTING.md) · [简体中文](../zh-CN/USAGE_REPORTING.md) · [日本語](../ja-JP/USAGE_REPORTING.md) · [한국어](../ko-KR/USAGE_REPORTING.md) · [繁體中文](../zh-TW/USAGE_REPORTING.md)

Monitor Go 与 Monitor Console 是独立仓库、服务和数据库，源码与数据目录分别保存。安装 Monitor Go 只需本公开仓库，不依赖私有 Console 源码。首次安装连接配置的 Console 在线登记；后续本地登录、监控和告警独立运行。

标准新安装须先在线激活，再创建首个本地管理员。页面展示确切目的地、统计用途、字段和持续上报且没有关闭开关的规则，要求明确确认告知版本 `2`。登记失败不创建管理员，恢复后以同一随机身份重试。产品使用者不需要 Console 账号。

统计独立安装量、活跃安装量及产品版本/系统分布：v2 登记请求为 `instanceId`、`credential`、`version`、`os`，后续上报为 `instanceId`、`version`、`os`、`activeDays`。随机编号用于去重，独立凭据仅用于认证，活跃标记按 UTC 日期汇总。版本和系统类型仅作为技术分布，不关联产品用户账号；不发送架构、部署方式、成员列表、主机名称/IP、监控内容、文件、密码或监控/应用密钥。匿名统计 User-Agent 固定，不附构建版本。

产品用户账号绑定、绑定码、用户列表和我的实例功能已退役。Console 仅保留后台管理员自身的认证信息，用于管理统计后台；这些管理员账号不是产品使用人数。Monitor Go 的本地管理员、成员与权限功能继续独立工作。

统计按随机安装身份去重，不代表自然人数。同一安装多人使用仍算一个安装；克隆数据目录可能合并统计，重新创建空数据目录可能产生另一个安装。登记成功后若本地初始化失败或取消，Console 可能保留随机登记，因此登记数也不等于已完成的安装数。

独立任务在激活后上报，此后约每 6 小时加入随机错峰；请求 5 秒超时、禁止重定向并采用有上限的退避。最多保留 7 个待发送的 UTC 活跃日期；单纯页面加载和自动刷新不计活跃。Console 每日记录保留 90 天，365 天未上报的安装会清理，后续报告可重新登记。

目的地不变时，升级保留随机身份、凭据、启用状态、历史确认及活跃日期。减少字段不补造新的同意，告知版本仍为 `2`。旧版关闭的安装须管理员确认当前目的地和规则，登记成功后才启用；等待确认或 Console 不可用时，本地登录、监控和告警继续运行。更换接收方必须先确认新目的地，才会向其发送。激活后的持续上报仍没有关闭开关，关闭请求返回 HTTP 403。

先升级 Monitor Console 到结构版本 `3`，再升级 Monitor Go 到结构版本 `11`。新版客户端使用 `/api/v2/instances/register` 与 `/api/v2/instances/report`；Console v1 登记/上报继续兼容旧客户端，保留版本与系统类型，接收架构和部署方式后丢弃，不持久化或回传。绑定接口已退役。Monitor Go v11 物理删除 `usage_settings.account_login` 旧账号快照；Console v3 移除架构、部署方式、账号关联和绑定码，保留版本/系统分布及匿名计数。

升级前正常停服并分别完整备份两个服务的数据目录；回退时恢复各自的旧镜像/二进制和整套升级前备份，不能将两者的数据库混用。保留的旧备份可能仍含旧元数据，应按私密备份管理。无需清空 Monitor Go 数据重新激活已确认的同目的地安装。

`MONITOR_CONSOLE_URL` 未设置时使用内置预设 HTTPS 来源，实际地址以安装或确认页面为准；显式环境变量覆盖预设，`-console-url` 优先于环境变量。继续使用原后台时，请在升级前显式配置其 HTTPS 来源。空或纯空白目的地无效。旧的 `-require-activation=false` / `MONITOR_REQUIRE_ACTIVATION=false` 被拒绝，`true` 保持兼容；版本查询和备份命令不依赖激活配置。

仅支持 HTTPS；数字回环 HTTP 只供隔离联调。不要将凭据、数据目录或备份提交 Git，统计服务代理日志不要保留完整来源 IP 或凭据。`MONITOR_DEPLOYMENT` / `-deployment` 仍标记本地运行方式，但不再作为匿名统计字段发送。

```sh
./bin/monitor -data data -listen 127.0.0.1:5080
```
