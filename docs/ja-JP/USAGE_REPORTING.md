# 任意の利用状況送信

[English](../en-US/USAGE_REPORTING.md) · [简体中文](../zh-CN/USAGE_REPORTING.md) · [日本語](../ja-JP/USAGE_REPORTING.md) · [한국어](../ko-KR/USAGE_REPORTING.md) · [繁體中文](../zh-TW/USAGE_REPORTING.md)

Monitor Go と Monitor Console は独立したリポジトリとサービスです。同階層のディレクトリに配置し、データを分離してください。統計サーバーがなくても監視は動作します。

両方のプロジェクトを保守する場合は、ソースを同階層の別ディレクトリに置き、データも分離します。通常の Monitor Go の導入にはこの公開リポジトリだけが必要です。任意の送信には接続可能な統計サービスが必要ですが、非公開のソースへのアクセスは不要です。

新規インストールと、この機能のない旧バージョンからの更新では送信は既定で無効です。送信先には `https://feiniu.i7f.cn:5090` が設定されています。`system:settings` 権限の管理者がシステム設定で送信先と項目を確認し、明示的に有効にします。URL の既定値だけで送信が有効になることはありません。再起動や更新では同じ送信先への選択を維持し、送信先の変更には再同意が必要です。

送信項目はランダムなインストール ID、バージョン、OS、CPU アーキテクチャ、配備方法、ログインした人が画面を操作した UTC 日付です。ローカルアカウント一覧、監視対象、ホスト名/IP、ファイル、アラート本文、パスワード、監視用キー、アプリケーションキーは含みません。インストール認証情報は登録と認証にのみ使用し、画面には表示しません。Console のアカウントは Monitor Go と独立しています。ローカルアカウントはユーザー名と表示名を保持し、任意の GitHub ログインでは検証済み GitHub ID、ユーザー名、表示名を別途保持します。

インストールの登録と活動統計にアカウント連携は不要です。Console はローカル管理者のユーザー名とパスワードでログインでき、GitHub ログインは任意です。Monitor Go の導入に OAuth 設定は不要です。

任意でアカウントを関連付けるには、ローカル Console アカウントまたは有効な GitHub ログインで Monitor Console にログインし、有効期限 10 分の使い捨て連携コードを生成して Monitor Go の送信設定に貼り付けます。先に送信を有効にしてください。連携解除はアカウントとの関連付けのみを解除し、送信は停止しません。コンソールから自分のインストールの連携も解除できます。

「前回同期した Console アカウント」はローカルに保存された情報です。Monitor Console 側で連携を解除した場合、Monitor Go の表示は次回の送信が成功した後に更新されます。送信を無効にしている間はコンソールに接続しないため、以前のアカウントが表示されたままになる場合があります。「送信状態を更新」はローカルの設定を読み直すだけで、コンソールへの問い合わせやリモート同期は行いません。

有効化後に独立した処理が一度送信し、その後は約 6 時間ごとに間隔を分散して送信します。タイムアウトは 5 秒で、リダイレクトを許可せず、制限付きのバックオフで再試行します。未送信の活動日は最大 7 日です。自動更新やページ読み込みだけでは利用とみなしません。日別集計はインストール単位で重複を排除し、人数は示しません。自己申告の推定値であり、身元や全インストール数の証明ではありません。

いつでも無効にできます。進行中の送信を中止し、未送信の活動記録を消去します。監視、アラート、ログインは独立して動作します。受信済みの履歴は削除されません。日別記録は 90 日、報告のないインストールは 365 日で削除します。その後再登録した場合はアカウントの再連携が必要です。

HTTPS が必要です。数値ループバックの HTTP はローカル統合テスト専用です。コンテナー内のループバックは自身を指すため、別コンテナーには実際の HTTPS URL を使用します。認証情報、データやバックアップを Git に保存しないでください。プロキシログには OAuth のクエリ、完全な送信元 IP や認証情報を残さないでください。

スキーマ 9 は送信設定と活動日のみを追加します。更新前に完全バックアップを取得してください。戻す際は元のバックアップが必要です。識別子はデータディレクトリに保持され、複製すると統計が合算される場合があります。無効化、オフライン、変更されたインストールを網羅することはできません。

`MONITOR_CONSOLE_URL` が未設定の場合、ネイティブ版と Compose は `https://feiniu.i7f.cn:5090` を使用します。別の HTTPS オリジンを指定して送信先を変更するか、`MONITOR_CONSOLE_URL=` と明示的に空にして送信先を未設定にできます。ネイティブ版の `-console-url` 引数は環境変数より優先され、`-console-url=` でも送信先を未設定にできます。

```sh
./bin/monitor -data data -listen 127.0.0.1:5080
```

`MONITOR_CONSOLE_URL` / `-console-url`; `MONITOR_DEPLOYMENT=native|docker` / `-deployment`.

ネイティブ版の既定値は `native` です。Docker イメージと Compose は自動的に `docker` を設定します。
