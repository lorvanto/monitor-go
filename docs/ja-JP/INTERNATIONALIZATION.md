# 翻訳の保守

[English](../en-US/INTERNATIONALIZATION.md) · [简体中文](../zh-CN/INTERNATIONALIZATION.md) · **日本語** · [한국어](../ko-KR/INTERNATIONALIZATION.md) · [繁體中文](../zh-TW/INTERNATIONALIZATION.md) · [Documentation](../README.md)

`locales/*.json`をGoとReactで共有します。対象は`zh-CN`、`en-US`、`ja-JP`、`ko-KR`、`zh-TW`です。Goは埋め込み、Reactは英語以外の言語を必要時に読み込みます。原文をgettext形式のキーとして使い、フロントエンドはキーの型を検査します。

- 固定文言は`t()`で表示し、変数付きの文は`{p0}`、`{p1}`でまとめます。文の断片を連結せず、HTMLとして出力しません。
- ラベル表は`localizedLabels()`を使います。`metadataLabel()`は固定の権限・スコープ情報専用です。利用者の名前や保存済み記録を一括置換しないでください。
- `web/src/i18n/`に言語選択と反応性、`lib/types.ts`に型、`format.ts`に日付・数値書式を分離しています。`stores/app.ts`は業務状態を管理します。
- 初回はブラウザーの言語に関係なく英語を使用します。有効な保存済みの選択は復元し、未保存・無効・保存機能が利用できない場合は英語に戻ります。言語選択はブラウザーに保存します。フォームを再作成せず、入力値を保持します。タイムゾーンはブラウザーのローカル設定です。
- JSONとアップロード要求は`Accept-Language`を送ります。APIは重みを考慮し、`Content-Language`と`Vary`を返します。ヘッダー省略時は従来の簡体字、未対応の場合は英語です。状態コードやJSON項目名は変更しません。
- 時間範囲は`1h`／`24h`／`7d`、完全削除は`DELETE`の固定値を使います。画面の翻訳を業務条件にしません。サーバーは旧中国語の削除確認値も受け付けます。
- Goの数値付きエラーは`badf()`で言語決定後に書式化します。全言語でプレースホルダーを揃えてください。
- 変更していない標準メニューのみ`nameKey`で翻訳します。独自名、履歴、診断、通知本文、ログ、CLIヘルプは原文のままです。

新言語は完全なJSONを作成し、Goの`Supported`／`Match`、フロントエンドの言語定義／マッチング／読み込み表、検査スクリプト、テスト、文書リンクを更新してください。現在は左から右の言語のみです。RTL言語では方向とレイアウトの対応も必要です。

```sh
npm --prefix web run check:i18n
npm --prefix web run check:docs
npm --prefix web run test:docs
npm --prefix web test
npm --prefix web run typecheck
npm --prefix web run build
npm --prefix web run format:check
go test -race ./...
go vet ./...
```

`prettier 3.6.2`は開発時の書式統一用です。ロックファイルを保持します。隔離したSQLite実ファイルで、ログイン前の切り替え、選択の保持、編集中の値、APIエラー、ファイルアップロード、狭い画面を検証してください。

現在の利用ガイドは5言語で提供します。過去の中国語設計文書はすべて翻訳済みではなく、将来案も含みます。起動方法・前提バージョン・製品の制限を変更する際は、各言語の現行ガイドを同期します。訳文は全キーを揃えていますが、母語話者による表現の改善も歓迎します。
